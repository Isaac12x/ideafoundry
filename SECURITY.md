# Security policy

Idea Foundry is local-first software intended to keep a user's ideas and research on their own machine. Please treat vulnerability reports as sensitive: they may involve private data, credentials, encryption, or local files.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/Isaac12x/ideafoundry/security/advisories/new). Do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Include the affected version or commit, relevant environment and configuration, steps to reproduce, security impact, and any suggested fix. Share only what is needed to demonstrate the issue. Do not include real idea content, databases, credentials, or other personal or secret data; use synthetic examples and redact logs where possible.

The maintainer may ask for clarification through the private report. Please coordinate public disclosure with the maintainer so users have an opportunity to update.
