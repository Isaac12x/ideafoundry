title: Using the app

Short notes on behaviour that is not obvious from the screen. Everything here runs locally.

## Command palette

Open it from the header or its shortcut. Three modes, switched with the chips or Alt+1 / Alt+2 / Alt+3:

- **Quick**: jump to ideas, projects, KB files and pages. Type `>` first to list commands.
- **Similar**: results close in meaning to a typed phrase, or pick **Find similar** on a result.
- **Deep**: searches inside idea text, notes and KB files, and highlights the matching words.

With a result selected, press **→** (at the end of the input) to see its actions, **←** to return to the previous search with your query intact. This works for ideas, projects and files.

## Find in page

Ctrl/Cmd+F opens a find bar styled like the app. Press Ctrl/Cmd+F again to hand over to the browser's own find.

## Knowledge base

- **Tree**: click the tree and use the arrow keys to move and open or close folders, Enter to open. Typing letters jumps to the next entry starting with them.
- **Projects**: in any project text field type `@` to link an idea (pick a specific version to link to that version rather than the latest), a maxim, a problem, a pipeline, or another KB file inside or outside the project.
- **Tests and "Requires"**: a test can require one or many items, linked with `@`. A pasted external link is imported: its content is stored with the test, not just a clickable link.
- **Draw**: the **Draw** button in a project field opens a drawing; saving inserts it at the cursor.
- Blank lines in saved project text are kept.

## Licensing

Mark an idea for licensing and use its **Licensing** tab: free-form licensing notes (where and to whom), plus prospects with stages and contact logs. The Licensing CRM shows all prospects. Prospects can be imported from a spreadsheet.

## Privacy haze

The camera-based haze (**Settings > Security**) needs an enrolled Face ID.

- **Per screen**: calibrate on each screen you use (laptop, external monitor above or beside it). The app asks the first time it sees an uncalibrated screen, so the window on the "other" screen works.
- **Turning it off** (switch, shortcut, or removing/replacing Face ID) is only allowed while the verified owner is looking at the screen and the haze is clear. If the camera is missing or broken the haze cannot work, so the switch is released.
