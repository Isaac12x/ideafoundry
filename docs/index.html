Idea Foundry

A private workspace for entrepreneurs to capture raw ideas, score their potential, organize the work, map relationships, and keep a full history as concepts move from spark to shipped.

Install locally Explore features

What it does

Turns scattered ideas into a working portfolio.

Idea Foundry is built for one person who needs a serious system without multi-tenant overhead. It combines intake, lifecycle states, weighted scoring, notes, templates, boards, drawings, and relationship maps in a local-first Rails app.

  1. Capture Record ideas directly, send them by email, or start from reusable templates.
  2. Assess Score TRL, difficulty, opportunity, and timing with configurable weights.
  3. Shape Use notes, drawings, todo lists, and rich text to develop the strongest concepts.
  4. Ship Move ideas through validation, backlog work, export, and backup workflows.

Core system

Built for repeated decisions.

The app keeps both the strategic view and the working detail close at hand, so an idea can be ranked, connected, revised, and recovered without leaving the workspace.

Lifecycle pipeline

Track ideas from new intake through triage, trials, cool-off, validation, shipping, parking, or rejection.

Weighted scoring

Compare ideas with configurable criteria and trend history instead of relying on gut feel alone.

Boards and lists

Organize ideas on kanban boards, custom lists, and optional build backlog lanes.

Topology graph

Explore categories, parent-child relationships, and adjacent concepts in an interactive 3D graph.

Version history

Snapshot each idea, compare revisions, and restore earlier versions when a direction needs to be recovered.

Exports and backups

Create encrypted or archive exports and schedule daily backup notifications for local resilience.

Run it privately

Local by design.

Idea Foundry is a single-user app intended for local machines or private servers behind network-level access control.
