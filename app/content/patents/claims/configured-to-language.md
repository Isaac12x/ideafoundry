"Configured to" ties a structure to a function: "a processor configured to compare X to Y". It is the usual way to give software-type elements a structural hook without invoking 112(f).

Meanings in practice:
- **Configured to / programmed to / designed to**: the structure is actually set up for the function; courts treat it as a real limit.
- **Capable of / adapted to** (varies by case): can be read more broadly, so check how the term is used in the specification.
- **Wherein clauses**: intended-use or result language ("wherein the user is protected") may get little patentable weight (MPEP 2111.04).

Example: "A mobile device comprising a camera and a processor configured to decode a code and compare a hostname to a list." The processor must actually carry out the functions; a device that can merely be reprogrammed is not clearly covered.

Tip: where a generic "module configured to" appears with no structure behind it, the claim risks a 112(f) reading (see Williamson). Pair it with a processor, memory, or circuit and disclose the algorithm.
