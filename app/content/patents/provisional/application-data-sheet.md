The application data sheet (ADS, 37 CFR 1.76) is a structured document listing the bibliographic facts of an application.

Typical contents:
- Inventor names and residences, applicant, assignee, correspondence address.
- Title, and entity status where relevant.
- Domestic benefit claims (provisional, parent applications).
- Foreign priority claims.
- Publication preferences and other administrative choices.

Why it matters:
- For applications filed after 16 Sept 2012 it is the required place for benefit and priority claims. A sentence in the description is not enough.
- It also identifies inventors, which affects who must provide a declaration.
- If its details conflict with other papers, errors can cause delay, a wrong inventor list or a lost claim, so keep it consistent.

How: the USPTO offers a fillable ADS (check the official forms page for the current version). It can be filed with a new application or later; corrected versions mark changes. Benefit claims filed late need a petition.

For a provisional, a cover sheet or an ADS can supply the inventor and title details.

Example: when converting a provisional, add its number and filing date in the benefit section of the ADS.
