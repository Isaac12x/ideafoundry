Provisionals need no claims. Including claim-like text is optional and still useful.

Why include them:
- They force you to write support for each feature you may later claim.
- They anchor the invention's key points.
- They speed up conversion into formal claims.

Risks:
- Narrow wording ("consisting of", "the invention is") can read as a limit on what you disclosed.
- Claims are not examined, and a disclaimer line ("illustrative only") does not change what the text legally supports.
- Claims are not a substitute for a full description. A later claim is entitled to the provisional date only if the provisional text itself supports it.

Practice:
- Place claim-like paragraphs after the description, labeled as example embodiments or numbered clauses.
- Write broad, then add narrower variants and different categories (method, system, storage medium).
- Use "comprising"-style open language.
- When converting, drop the heading and map each claim term to provisional text.

Example: "1. A method comprising receiving an image, decoding a code in it, and comparing a result to stored data. 2. The method of claim 1, where the stored data is a local cache." Both should be described elsewhere in the text with working detail.
