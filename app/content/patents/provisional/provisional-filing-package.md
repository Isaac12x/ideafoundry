Needed for a filing date: a specification that meets 35 USC 112(a) (describes and enables), plus any drawings needed to understand it.

Also submitted:
- A provisional cover sheet (inventor names, title, correspondence details) or an application data sheet. If left out, the USPTO issues a notice and a later deadline, sometimes with a surcharge.
- The filing fee, set by entity size.

Not required: claims, abstract, oath or declaration, information disclosure statement, formal drawing format.

Steps:
1. Write the description: problem, system, methods, variants, advantages, working examples, code snippets, consistent terminology.
2. Add drawings (rough is acceptable; see the minimum figure set).
3. Combine into one PDF, or DOCX where Patent Center accepts it.
4. File through Patent Center and pay the fee.
5. Save the filing receipt and application number; check the receipt for correct names and title.

Quality checklist: all embodiments included; no trade names or marketing talk; each numeral explained; alternatives stated; no "consisting of"-style limits.

Then diarize the 12-month deadline immediately.

Example: a 25-page PDF with 6 figures and a cover sheet, uploaded as a provisional.
