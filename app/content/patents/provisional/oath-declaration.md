Each inventor of a non-provisional application must give an oath or declaration (35 USC 115, 37 CFR 1.63): they believe they are the original inventor (or joint inventor) of the claimed invention, and the application was made or authorized by them.

Points:
- Provisionals: none needed.
- Non-provisionals: not required on the filing date if an application data sheet names the inventors. It can be filed later, typically before the issue fee; check the notice for deadlines and any surcharge.
- Natural persons only: an AI system cannot be an inventor (see AI-assisted inventorship).
- Assignment is separate. A declaration states inventorship; an assignment transfers ownership. An assignee-applicant can file, but inventors still declare.
- Inventor unavailable or unwilling: a substitute statement can be filed, with conditions.
- One declaration can cover several related applications (e.g., a continuation) if it identifies the original and the inventors have not changed.
- It must match the inventor names in the data sheet.


Example: you file a non-provisional with an ADS naming two inventors; each signs and uploads a declaration three months later after the notice.
