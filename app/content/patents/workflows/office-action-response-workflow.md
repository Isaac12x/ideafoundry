1. Docket the response deadline from the action's mailing date; extensions cost fees.
2. Read every rejection by statute: eligibility, 102, 103, 112, double patenting.
3. For each rejected claim, make an element chart: claim term vs cited passage.
4. Decide per rejection:
   - Reference lacks a term: argue.
   - Term is read too broadly: argue construction, citing the spec.
   - Reference too close: amend, and argue.
   - Unsure: consider an examiner interview.
5. Obviousness arguments: no motivation, teaching away, unexpected results with real data, secondary considerations tied to the claims.
6. Amend only with support in the original application; no new matter.
7. Know the cost: narrowing amendments for patentability can limit equivalents (Festo).
8. Keep a broader claim set alive via continuation if narrowing is strong.
9. Address each issue, including formalities; unanswered rejections lose.
10. Disclose newly known relevant references (information disclosure).
11. File through Patent Center; keep the receipt.
12. If final, weigh amendment after final, RCE, appeal, or continuation.

Tone: factual, specific, no personal statements about the examiner.

_Educational, not legal advice._
