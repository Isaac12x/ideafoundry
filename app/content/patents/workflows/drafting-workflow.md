Order of work (claims first, text follows the claims):
1. Write the invention in one paragraph: problem, technical solution, effect.
2. Search prior art first (see prior-art-search); note what is close.
3. List functional elements and alternatives for each.
4. For software, state the concrete technical improvement and the hardware it runs on (eligibility, see alice-two-step).
5. Draft broad-but-concrete independent claims: method, system, computer-readable medium.
6. Draft dependent fallbacks, one new limitation each (see three-tier-claim-set).
7. Write the detailed description: every claim term appears, with alternatives ("in some embodiments") and the technical-effect paragraph.
8. Draw figures: system, flow, data structure; numerals consistent (see drawings-workflow).
9. Write Summary (mirrors independents), Brief Description of Drawings, Field, neutral Background, Abstract (150 words or fewer).
10. Map claim terms to spec passages; fix gaps in the spec, not by changing claims after filing.
11. Check antecedent basis and dependency chains.
12. Run pre-filing-qc.

Rules of thumb:
- Add alternatives now; new matter cannot be added later.
- Do not state results you have not obtained; use prophetic wording.
- Use consistent terms between claims, text and figures.

_Educational, not legal advice._
