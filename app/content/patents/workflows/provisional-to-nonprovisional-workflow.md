There is no upgrade button. File a new non-provisional that claims benefit of the provisional within 12 months.

Timeline: month 0-3 review and decide; month 3-9 draft; file before month 12. File foreign (PCT or Paris) the same deadline.

Steps:
1. Calendar the 12-month date (weekends/holidays may roll it, don't rely on it).
2. Read the provisional; list every feature and alternative disclosed.
3. Draft formal claims: one independent set per category, dependents as fallbacks.
4. Support-map each claim term to provisional text. Matter only in new text gets the new date, not the provisional date.
5. Rewrite into standard sections: field, background, summary, drawings description, detailed description, abstract.
6. Add new detail and new figures if needed, accepting that new matter has the later date.
7. Convert any sketches to formal drawings; keep numerals consistent.
8. Add a benefit claim in the application data sheet; add an incorporation-by-reference sentence as a backup.
9. Delete the "Example Claims" heading; real claims go under "Claims".
10. Run pre-filing-qc; file through Patent Center.

Multiple provisionals can feed one non-provisional; each claim gets the date of the provisional that supports it.
