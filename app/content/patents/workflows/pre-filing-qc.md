Run in this order the day before filing.

1. Filing type: provisional, non-provisional or PCT? Confirm deadline math (12 months from priority).
2. Package complete: specification, claims, abstract (150 words or fewer), drawings, application data sheet, inventor declaration (may be postponed for non-provisionals; not needed for provisionals), fee payment.
3. Consistency:
   - Terms identical in claims, text and figures.
   - Every reference numeral in text appears in a figure and vice versa.
   - Every "the X" in claims has an earlier "a X".
   - No circular or missing dependencies.
4. Support: each claim element has a spec passage (see claim-to-spec-mapping).
5. Priority/benefit: claims in the application data sheet; incorporation by reference sentence added.
6. Formatting: legible font, spacing, numbered pages, FIG labels, claims on their own page, no tracked changes or comments left in files.
7. Entity status and fees: confirm eligibility; use current USPTO schedule.
8. Disclosure check: has anything been published, sold or shown? (see disclosure-before-filing)
9. Prior art: list known references for the information disclosure statement.
10. File via Patent Center; save the filing receipt and filing date confirmation.

After filing: check the receipt for errors within days; calendar deadlines (12-month, foreign, issue fees).
