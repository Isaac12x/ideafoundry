1. List what every claim needs shown (see minimum-figure-set): system overview, method flowchart, key data structure, UI or device if claimed.
2. Sketch each figure by hand; mark which claim element each box serves.
3. Redraw as clean black-and-white line art in a vector tool (diagram tool, CAD for mechanical).
4. Add reference numerals: numbers only, consistent across figures, same part same numeral, never reused for different parts.
5. Label each view "FIG. n" and number sheets per the rules.
6. Check text legibility after size reduction.
7. Cross-check with the description: every numeral in the text appears in a figure and vice versa.
8. Export as PDF, black and white, sized to the allowed page area; one PDF or per-figure files as the system accepts.
9. QA at reduced zoom: no gray fills, no broken lines, no text cut off.
10. Add new drawings only before filing; after filing they count as new matter.

When to hire a draftsperson: mechanical assemblies, complex perspective views, or when a practitioner files for you.
