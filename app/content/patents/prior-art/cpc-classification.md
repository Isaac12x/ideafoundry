The Cooperative Patent Classification (CPC) is the shared EPO/USPTO scheme that sorts patent documents by technology. A class code is a hierarchy: section, class, subclass, group (for example G06F is electrical digital data processing; H04L covers digital information transmission).

Why use it:
- Finds documents that use different words for the same idea.
- Lets you search within a class once you spot one relevant patent: copy its CPC code from the record and search that code.
- Examiners search by class, so reading classes on cited references hints at where the examiner will look.

Limits:
- Classification is assigned by examiners and can be wrong or inconsistent; always combine it with keyword searching.
- Older documents may carry only legacy classes (the old US scheme is retired); check which scheme a record shows.

Example (illustrative): a QR URL-checker hit lists G06K (recognition of data) and H04L 63 (network security). Searching those groups finds papers that never say "QR".

Record each code you searched in your search log.
