A claim-to-specification map is a table linking every limitation of every claim to the paragraph(s) and figure(s) that support it. It is the practical way to check written description and enablement before filing.

How:
1. List each independent and dependent claim limitation.
2. Find the paragraph (and figure reference numerals) that expresses it.
3. Mark gaps; fix by adding specification text before filing (adding later risks new matter).
4. Check terminology: claim words should appear in the specification, or be clearly equivalent.

Example row: Claim 2 "database stored on the mobile device" -> [0032], FIG. 3 (item 308).

Also map the other direction: if the specification says it, consider whether a claim should cover it. For provisionals, a map shows which claims the provisional supports so the priority date can be defended.

Tip: do it per claim category: a method claim supported only in a system paragraph may fail. Keep the map with the drafting file for later amendments.

_Educational, not legal advice._
