Any tool is fine if the output meets the drawing rules: black line art, clean lines, legible numerals, correct margins.

Tool types (from the source, lightly pruned):
- Software, flowcharts, block diagrams: Visio, Lucidchart, draw.io. Export to PDF.
- Mechanical: SolidWorks, AutoCAD, Fusion 360 for orthographic views; then strip shading and fills.
- General vector: Illustrator, CorelDRAW, Inkscape (free).
- Patent-specific drafting software enforces margins and numbering automatically.
- Rough DIY: paper, tablet, PowerPoint. Fine for a provisional; redraw clean for a non-provisional.

Output:
- Vector PDF preferred, so lines stay crisp when zoomed. Raster, if unavoidable: 1-bit black and white, at least 300 dpi.
- Submit PDF through Patent Center. Do not submit TIFF.
- One multi-page drawings file, figures in numerical order, separate from the specification file.
- Simple sans-serif or serif font, numerals at least 0.32 cm tall.
- QA: view at about 66% zoom. If lines and numerals are still crisp, the two-thirds reduction test passes.

Hire a professional illustrator when you need mechanical perspective views, plan foreign filings with strict line and numbering rules, or want to avoid a drawing objection.

Example: draw a software architecture in draw.io using black outlines only, number each box 100, 102, 104, export PDF, then check margins against the drawing rules.

_Educational, not legal advice._
