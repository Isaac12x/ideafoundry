A divisional is a continuing application filed to pursue an invention the examiner required you to give up (elect against) in a restriction requirement. Same disclosure, no new matter, same benefit date, same 20-year term clock as the parent.

Flow:
1. Application claims a method and an apparatus.
2. Examiner restricts: pick one group.
3. You elect the method; the apparatus claims are withdrawn.
4. Before the parent issues, file a divisional for the apparatus.

Cautions:
- Not risk-free. Double patenting still gets analyzed between family members.
- 35 USC 121 offers a safe harbor from double patenting for divisionals filed because of a restriction, but courts read it narrowly. It generally does not shelter continuations or CIPs, and it can be lost if claims are not kept consistent with the restricted groups.
- If a terminal disclaimer is needed, the patents expire together and must stay commonly owned for enforceability.
- Voluntary splitting (no restriction) is just a continuation, with no safe harbor.

Tip: do not voluntarily amend claims in the parent to a different group than the restriction drew.
