A picket fence is a set of related patents, each claiming a different aspect or variant of one invention, so a competitor cannot simply design around a single claim.

Ways to build the pickets:
- Claim categories: method, system, computer-readable medium.
- Architecture variants: on-device vs server vs hybrid.
- Features: caching, scoring, security.
- Alternatives: a different algorithm achieving the same result.

Benefits:
- Each patent is separate, so invalidating one does not take down the rest.
- A design-around has to avoid several claim sets at once.
- Licensing: sell or license subsets.

Cautions:
- Claims must be patentably distinct or need terminal disclaimers.
- Every patent costs fees and attention; maintain only those that matter.
- Pickets can only cover what the shared spec supports.

Example: picket 1 claims on-device hash filtering; picket 2 the server-assisted scoring path; picket 3 the stored-media variant.
